# 全站编辑弹窗未保存保护设计

## 目标

所有新增、修改及业务操作弹窗不再因误点遮罩丢失内容。

## 统一行为

- 点击弹窗外灰色遮罩不执行关闭。
- 关闭按钮和取消按钮统一经过关闭守卫。
- 表单相对初始快照有变化时提示“当前修改尚未保存，确定放弃吗？”。
- 用户确认才关闭；取消确认后继续编辑。
- 没有变化时直接关闭。
- 保存中拒绝关闭。

## 组件设计

新增复用组合函数 `useUnsavedChangesGuard`，接收当前表单快照函数、保存状态和最终关闭回调。它在初始化完成后记录规范化 JSON 快照，并提供 `markClean()` 与 `requestClose()`。数组和明细行包含在快照中，因此订单、采购、售后、合同等动态明细同样受到保护。

编辑型弹窗移除遮罩 `@click.self` 关闭行为，并将顶部关闭、底部取消统一绑定 `requestClose()`。纯查看弹窗不涉及未保存数据，但也取消遮罩关闭，保持全站一致。

## 验证

组合函数单元测试覆盖无修改直接关闭、有修改确认、取消确认、保存中禁止关闭；代表性客户、产品、订单和售后弹窗测试覆盖按钮接入及遮罩不关闭。全量前端测试确保其他弹窗行为不回归。
