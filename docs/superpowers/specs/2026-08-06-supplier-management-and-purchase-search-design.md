# 供应商管理与采购模糊选择设计

## 目标

在不影响已存在采购、库存和财务关联的前提下，将采购录入界面由内部 ID 输入改为按名称模糊选择，并提供供应商与其可供产品的维护入口。

## 方案选择

采用方案 A：界面只显示业务名称；内部继续使用供应商 ID 与产品 ID 建立外键关联。相比允许自由文本采购，该方案能防止生成无法追溯的采购记录，同时不向用户暴露数据库 ID。

## 数据模型

- 复用现有 `supplier` 表作为供应商主数据，列表显示供应商名称、联系人、联系电话、银行账户、修改时间。
- 复用 `sku_supplier_config` 维护“供应商可供产品”；一条产品只能有一条当前启用的供应配置，沿用现有唯一约束。
- 供应商编辑时可以为其添加、修改或移除产品配置；每项配置包含产品、采购单价、最小起订量和交货天数。
- 删除配置只解除供应商与产品的可供关系，不删除产品、供应商以及任何历史采购记录。

## 后端接口与行为

- 新增 `supplier` 列表模块，支持名称、联系人和电话模糊查询，以及按修改时间倒序排列。
- 新增供应商新增、编辑接口和供应产品配置保存接口；供应商名称为必填项。
- 增加采购录入可选项接口，返回供应商与产品的名称、内部 ID、配置采购价、起订量及交货天数。
- 手工采购请求改为使用已选择项的内部 ID；前端只提交选择结果。后端验证供应商、产品以及它们的配置关系均存在且启用。
- 采购列表查询和搜索移除 `supplierId`、`productIds` 这两个展示及搜索字段，保留供应商名称与产品摘要。

## 前端体验

- 左侧导航新增“供应商管理”，置于产品管理之后、订单管理之前。
- 供应商管理沿用现有统一列表高度、修改时间排序和弹窗表单样式；点击“新增供应商”或“修改”可维护资料及产品供应关系。
- 手工采购表单中的“供应商”和“产品”改为可输入筛选的下拉选择器：输入任意名称、物料编号、型号或规格可缩小结果；产品列表随选中供应商限定为该供应商已维护的产品。
- 选中产品后自动带出默认采购单价，采购数量小于最小起订量时在输入框旁显示红色提示；交货天数可用于默认计算预计到货日期，但允许手动改期。
- 采购管理列表仅显示“采购单号、供应商、产品、采购金额、订单状态、预计到货、修改时间”。

## 兼容与异常处理

- 历史采购记录仍通过已有 ID 与供应商/产品关联；移除 ID 列仅影响界面展示。
- 没有供应产品配置的供应商可保存，但不能在手工采购中提交；页面明确提示先在供应商管理中维护产品。
- 选择内容失效、已禁用或不属于当前供应商时，保存前在相应字段旁给出红色提示，不创建采购单。

## 验证

- 后端覆盖供应商列表模糊查询、供应产品配置保存、采购可选项过滤与不匹配配置拒绝。
- 前端覆盖导航显示、供应商表单保存、采购按供应商筛选产品、价格带入与起订量错误提示。
