# 产品管理子菜单展开状态设计

## 目标

产品管理子菜单一旦展开，在用户切换到客户、供应商、订单、售后、库存、采购或财务管理时继续保持展开，不因页面切换自动折叠。

## 交互规则

- 产品管理子菜单的展开状态独立于当前激活模块。
- 点击其他管理页面只切换内容区和激活菜单，不修改 `productMenuOpen`。
- 用户在产品管理页面再次点击“产品管理”时，仍可主动切换展开或折叠。
- 从其他页面点击“产品管理”时进入产品列表并展开子菜单。
- 页面刷新后沿用当前初始化规则：仅当地址模块为产品管理时默认展开，不做本地持久化。

## 实现范围

- 仅调整 `frontend/src/App.vue` 的导航状态更新逻辑。
- 不改变“产品编号规则”页面内容、URL 参数、权限和其他菜单行为。

## 测试

- 新增导航回归测试：展开产品子菜单后切换到其他模块，子菜单仍存在。
- 保留现有产品菜单切换与产品编号规则入口测试。
