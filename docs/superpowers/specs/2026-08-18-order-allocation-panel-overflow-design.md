# 订单库存分配卡片遮挡修复设计

## 问题

“手动分配库存”弹窗使用纵向 Flex 列表展示产品卡片。列表设置了最大高度和滚动，但卡片仍使用默认的 `flex-shrink: 1`。产品较多时，浏览器会先压缩所有卡片，而不是让列表滚动，导致指标行和黄色分配区域被裁切。产品较少时空间充足，因此页面呈现不同。

## 设计

- 保持现有弹窗、产品卡片结构及库存分配业务逻辑不变。
- 产品卡片设置为不可收缩，使每张卡片始终按内容完整显示。
- 继续由产品列表容器承担纵向滚动，产品数量较多时通过滚动查看。
- 黄色“本次分配给客户”区域中的输入框和“可分配 0 至 N”提示必须完整可见。
- 保持现有窄屏断点行为，窄屏下黄色区域换到指标区下方。

## 验证

- 添加前端回归测试，断言产品卡片具有不可收缩布局规则。
- 运行前端测试和生产构建。
- 在本地浏览器分别检查少量和多量产品的订单，确认卡片结构一致、黄色提示无遮挡、列表可滚动。

## 非目标

- 不修改订单、库存或锁定数量计算。
- 不调整弹窗字段内容或数据接口。
- 不重构其他订单页面。
