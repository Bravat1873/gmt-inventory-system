# Salesforce Lightning 风格首页看板设计

## 目标

将现有首页重构为适合进销存日常操作的 Salesforce Lightning 风格工作台。重构仅覆盖首页，不改变其他业务页面、后端接口、实时数据订阅或模块跳转行为。

## 页面结构

1. 顶部操作栏：实时连接状态、7/30/90 天周期切换、刷新按钮。
2. 核心指标区：今日销售金额、缺货产品、待收款、待付采购、处理中售后。
3. 业务流程区：使用二维流程展示订单需求、可用库存、在途采购、待发货。
4. 分析与待办区：左侧业务趋势图，右侧产品待办队列。

## 视觉系统

- 浅灰蓝工作区与白色内容表面。
- Salesforce 蓝作为唯一主操作色，红色仅用于风险与负数。
- 4px 圆角、细灰边框、轻量阴影、紧凑间距。
- 不使用渐变、绿色黄色主题、Three.js、装饰动画或大型营销式标题。
- 页面保持较高信息密度，并使用清晰的层级和对齐。

## 组件行为

### 顶部操作栏

- 展示实时连接状态。
- 周期切换继续控制趋势数据的 7/30/90 天范围。
- 刷新按钮继续触发完整快照刷新。

### 指标区

- 五个指标均可点击进入相应业务模块。
- 今日销售金额作为主指标，其余指标保持同一视觉体系但降低权重。
- 缺货数量和异常状态使用红色语义，不以大面积颜色填充。

### 二维业务流程

- 顺序固定为：订单需求 → 可用库存 → 在途采购 → 待发货。
- 每个节点展示数值、名称和辅助说明。
- 节点之间使用细线和方向箭头表达业务流向。
- 点击节点筛选产品待办；再次点击取消筛选。
- 删除 Three.js、WebGL 画布和所有运动物体。

### 趋势图

- 图例明确为订单数、采购数量、发货数量、销售金额。
- 订单数使用细实线；采购和发货使用窄柱；销售金额使用细虚线并绑定右轴。
- 提示框展示日期与四项准确数值。

### 产品待办

- 按风险优先级排序。
- 完整展示客户料号、型号、产品编号，不使用省略号截断。
- 展示库存、在途、待交付和供需净值。
- 保留进入对应业务模块的处理操作。

## 响应式与可访问性

- 桌面端趋势图与待办列表左右布局；窄屏改为单列。
- 主内容区域支持纵向滚动，不产生页面级横向滚动。
- 交互控件具备键盘焦点状态，触控目标不小于 44px。
- 状态不能仅依赖颜色表达，同时保留文字标签与数值。

## 数据与错误处理

- 继续使用现有 dashboard snapshot 与 SSE 接口。
- 加载失败时展示可见错误信息和重试按钮。
- SSE 断开时保留最近一次数据并显示连接状态，不清空首页。
- 数据字段缺失时使用安全默认值，避免整个首页渲染失败。

## 验证

- 前端类型检查和生产构建通过。
- dashboard API 与 App 相关测试通过。
- 桌面和移动宽度下验证滚动、无横向溢出、节点筛选及模块跳转。
- 验证首页不再加载 Three.js 画布，默认根地址进入首页。
