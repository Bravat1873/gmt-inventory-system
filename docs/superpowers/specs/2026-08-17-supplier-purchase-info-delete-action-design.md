# 供应商采购信息删除操作优化

## 背景

供应商可以关联多个产品，每个产品又可以维护多条采购信息。当前每行同时显示“删除”和“移除产品”，且仅有一条采购信息时“删除”为禁用状态，容易被误解为按供应商的产品总数决定是否可删除。

## 设计

- “删除”改为“删除采购信息”，明确操作对象。
- 当某个产品只有一条采购信息时，不渲染“删除采购信息”。
- 当同一产品有两条或更多采购信息时，每条记录均显示“删除采购信息”。
- “移除产品”保持现有行为和文案，仅在该产品的首行显示。
- 不修改保存载荷、后端接口或“每个产品至少保留一条采购信息”的业务规则。

## 验收标准

1. 供应商有多个产品、但每个产品只有一条采购信息时，只显示“移除产品”。
2. 同一产品有多条采购信息时，显示“删除采购信息”，点击后只删除对应采购信息。
3. 现有“移除产品”操作仍可移除整个产品及其采购信息。
4. 组件测试覆盖单条隐藏、多条显示及删除后恢复隐藏三种状态。

## 测试策略

先新增组件测试并确认其因当前灰色“删除”按钮仍存在而失败，再修改模板条件和文案，最后运行供应商弹窗测试及前端完整测试。
