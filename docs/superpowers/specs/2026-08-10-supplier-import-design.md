# 供应商资料与表格导入设计

## 目标

在保持现有供应商管理页面视觉风格的前提下，补齐供应商资料字段，并支持 `.xls`、`.xlsx` 文件预览后导入。用户每次导入时可选择“覆盖更新”或“全量替换”。

## 数据字段

供应商保留现有字段：供应商编码、供应商名称、联系人、联系电话、银行账户、启用状态和关联产品。

新增字段：厂商分类、厂商类型、供应商地点、产品属性、简称、联系人职称、供应商地址、币种、税务登记号、开户地址。

供应商名称作为导入匹配键；供应商编码由系统为新增记录自动生成。银行账户、税号和电话始终按文本保存，保留空格和前导零。

## 导入流程

1. 供应商管理标题区域增加“导入供应商”按钮，沿用现有按钮和导入弹窗风格。
2. 用户选择 `.xls` 或 `.xlsx` 文件后，后端解析表头、规范字段并生成预览批次。
3. 预览展示有效行、错误行和标准化后的字段；此阶段不修改供应商表。
4. 用户选择导入策略：
   - `覆盖更新`（默认）：按供应商名称匹配；同名供应商以表格非空或空白内容完整覆盖，未匹配记录新增，文件外旧记录保留。
   - `全量替换`：再次确认后，以文件内容作为当前供应商资料全集；文件外旧记录不再出现在供应商管理中。
5. 只有整批校验通过才能执行全量替换；提交在单个事务内完成，失败时全部回滚。

## 历史数据保护

采购单等历史业务可能引用供应商主键，因此全量替换不直接删除被引用记录。系统优先按供应商名称复用现有记录；文件外的旧供应商改为停用并从默认供应商列表隐藏。没有业务引用的旧记录也使用停用策略，保证恢复和审计能力。重新导入同名供应商时可恢复启用并覆盖资料。

## 表格兼容与校验

- 支持当前文件的双行/非首行表头，自动寻找包含“供应商名称”的表头行。
- 接受列名：厂商分类、厂商类型、供应商地点、产品属性、简称、供应商名称、联系人、职称、联系方式、供应商地址、币种、税务登记号、开户地址、开户账户。
- 供应商名称必填且文件内不可重复。
- 电话、税号、银行账户按单元格显示文本读取，避免科学计数法和精度损失。
- 未识别列保留在错误提示中但不阻止导入；缺少必填列或存在重复名称则阻止提交。

## 页面表现

供应商列表补充核心字段，但保持当前表格、分页、固定行高、横向滚动和右侧操作列模式。编辑弹窗按现有表单组件补充字段，不引入新的视觉体系。导入弹窗复用现有预览组件，新增策略单选区；全量替换使用醒目警告和二次确认。

## API 与组件边界

- 后端新增供应商 Excel 解析器和 `SUPPLIER` 导入类型。
- 预览 API 复用 `/api/imports/preview`；提交请求携带供应商策略 `OVERWRITE` 或 `REPLACE_ALL`。
- 提交服务负责事务、按名称匹配、字段覆盖、自动编码和全量替换时停用文件外记录。
- 前端模块配置仅增加供应商导入类型；现有导入面板负责选择策略和确认。

## 测试与验收

- 解析 `.xls` 和 `.xlsx`，验证非首行表头及所有字段映射。
- 验证文本型电话、税号和银行账户不丢位数。
- 覆盖更新：同名覆盖、新名称新增、文件外记录保留。
- 全量替换：文件外记录停用、历史采购引用有效、失败整批回滚。
- 前端验证默认覆盖更新、全量替换二次确认和原页面风格不变。
- 使用用户提供的 `供应商联系方式.xls` 完成一次预览和本地导入验收。
