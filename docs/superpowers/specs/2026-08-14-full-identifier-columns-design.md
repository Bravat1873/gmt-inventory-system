# 编号列完整单行显示设计

## 目标

前端列表中的产品编号、订单编号、售后单号、采购单号和业务单号必须完整显示。编号保持单行，不换行、不显示省略号，也不因表格可用宽度不足而被压缩。

## 范围

修改统一列表组件 `ModuleListPage` 中以下字段的展示行为：

- `productCode`：产品编号
- `orderNo`：订单编号
- `afterSalesNo`：售后单号
- `purchaseNo`：采购单号
- `businessNo`：业务单号

其他字段继续使用现有的溢出省略与悬浮提示行为，避免备注、配置等长文本无限撑宽表格。

## 展示方案

统一列表组件根据字段名识别编号列。编号单元格使用专用的完整文本样式：`white-space: nowrap`、不隐藏溢出、不设置 `text-overflow: ellipsis`，并保持正常字号和字距，不通过缩放或压缩文字适配列宽。

上述编号列设置能够容纳当前业务编号格式的最小列宽。表格的整体最小宽度继续由各列宽度之和计算；当视口不足时，现有 `.table-wrap` 横向滚动承载额外宽度，现有固定操作列行为保持不变。

## 组件边界

通用 `OverflowText` 组件保持原状，因为其省略和悬浮提示仍适用于大多数普通字段。`ModuleListPage` 仅对指定编号字段选择完整文本渲染，其余字段继续走 `OverflowText`。

## 测试与验收

组件测试应覆盖：

1. 五个指定字段被识别为完整编号字段。
2. 指定字段渲染为完整文本元素，不使用 `OverflowText`。
3. 编号样式保持单行且不包含隐藏溢出和省略号。
4. 编号列宽计入表格最小宽度，视口不足时仍可横向滚动。
5. 其他普通字段继续使用原有省略行为。

验收时使用长编号数据确认文本内容全部可见、单行显示，操作列仍固定在右侧，页面不出现纵向行高膨胀。
